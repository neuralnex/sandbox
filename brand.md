# Sandbox brand

**Product:** Sandbox — an AI assisted workspace for constructing, running, and comparing reproducible experiments.

**Direction:** Bold, warm, technical. Borrow the direct, high contrast, graphic energy of creator products such as Gumroad while keeping Sandbox's own identity, layout, and SD monogram.

## Color system

**Palette: Soft Pop**

Two complementary combinations anchor the identity:

1. **Pink + ink** — `#FF90E8` on `#242423`; the welcoming signature accent and primary action.
2. **Teal + cream** — `#23A094` on `#F4F4F0`; a calmer supporting combination for data, labels, and secondary actions.

Light mode uses warm cream, near-black ink, bright pink actions, and teal accents. Dark mode uses charcoal surfaces, soft cream text, the same pink signature accent, and a brighter teal for readable secondary cues. Text on pink uses ink for contrast. Status colors are reserved for status.

## Typography

Use a clean system sans stack for the interface and a system monospace stack for seeds, model configuration, and identifiers. Keep headings short and human; use tabular figures for metrics.

## Voice and visual use

Be clear, curious, and grounded. Describe configurations as assumptions and results as model outputs. Never let visual polish make a simulation look like a factual prediction.

Use flat surfaces, crisp borders, restrained corner radii, and one main action per panel. Use pink for the primary action and focus; use teal for secondary meaning and progress. Avoid gradients, decorative stock imagery, or color used without semantic purpose.
